# B站 · 手机竖屏网页版

用于手机浏览器访问 B 站电脑网页版的油猴脚本，当前版本 **1.6.1**。

## 安装

[点击安装最新版脚本](https://raw.githubusercontent.com/c18556210950-art/bilibili-portrait/main/bilibili-portrait.user.js)（需要已启用用户脚本管理器）。

1. 在支持用户脚本的手机浏览器中启用 Tampermonkey 或兼容管理器。
2. 新建脚本，将 [`bilibili-portrait.user.js`](./bilibili-portrait.user.js) 的完整内容复制进去并保存。
3. 开启浏览器的“桌面版网站”，访问 B 站并刷新。

已安装旧版时替换完整脚本即可，原有设置保留。

## 功能

- 竖屏底部横排工具栏；手机横屏自动切换为右侧竖排，设置及搜索向左展开。
- 一列／两列视频列表、首页分类编辑、首页下拉刷新。
- 播放页面上下排列，合集／选集移到评论之前，取消滚动悬浮小窗。
- 倍速、快进快退、全屏、评论跳转及原生自动连播设置。
- 首页、历史、稍后再看、搜索、动态、空间、热门、分区及番剧影视页面的布局规则。
- 图文、课程、直播、消息等页面的补充规则；账号、创作中心、会员购、漫画、公益提供基础窄屏支持。

## 验证与限制

通过 148 项 DOM 行为检查；横屏工具栏检查了 844×390、568×320，以及旋回 390×844 和键盘短视口 390×250。

部分页面使用官方 CSS 和示例节点验证，不能替代真机和完整登录流程验证。真实手机油猴、直播、消息发送、付费播放、支付与管理流程尚未完整实测。脚本不绕过原站登录、会员、地区或付费权限。

详见[安装与使用说明](./安装与使用说明.md)。
